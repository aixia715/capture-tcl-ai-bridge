PSpiceTranRun

Runs transient analysis upto a specified run time.

Return

int

Syntax

PSpiceTranRun <runtime> <relativeTime = false>

Parameters

ParameterDescriptionTypeOptionalValue Required
runtime Stop time for transient analysis int false false
relativeTime True Stop time is relative to last run. False Stop time is absolute. bool false false

Examples

  • PSpiceTranRun 1 false
  • PSpiceTranRun 1 true

Related Commands

  • PSpiceTranEnd
  • PSpiceTranNextTime
